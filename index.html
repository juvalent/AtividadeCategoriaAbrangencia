Uso de IA na Organização de Dados

Uso de Inteligência Artificial para organizar e preparar dados de planilhas para criar um banco de dados.

📊 Situação escolhida

Uso de IA para organizar e preparar dados de planilhas para criar um banco de dados.

📥 Dados de entrada

A IA recebe informações desorganizadas presentes nas planilhas, como:

  • Nomes e informações de clientes
  • Produtos ou serviços
  • Datas e valores
  • Telefones e e-mails
  • Códigos e identificadores
  • Dados duplicados ou preenchidos em formatos diferentes
📤 Saída produzida

Uma base de dados organizada, pronta para ser utilizada na construção do banco de dados.

📊 Planilha desorganizada ↓ 🤖 IA organiza os dados ↓ 🗄️ Base de dados estruturada
✅ Benefício

Reduzir o tempo de preparação dos dados e diminuir erros manuais, facilitando a transformação de informações desorganizadas em uma estrutura adequada para um banco de dados.

🧠 Por que este caso envolve IA?

A IA pode reconhecer padrões, identificar inconsistências e sugerir uma organização dos dados a partir do conteúdo das planilhas.

👩‍💻 Supervisão humana

É importante que uma pessoa revise as alterações realizadas pela IA, verificando:

  • Se os dados foram classificados corretamente;
  • Se nenhum dado foi excluído;
  • Se os relacionamentos sugeridos entre tabelas são adequados;
  • Se existem informações duplicadas ou ausentes;
  • Se a estrutura final do banco de dados está correta.

A pessoa deve aprovar a estrutura final antes da implementação do banco de dados.

⚠️ Limitações
  • A IA pode interpretar algum dado de forma incorreta.
  • Pode excluir ou alterar informações que considera duplicadas.
  • Pode criar relacionamentos inadequados entre dados.
  • Dados sensíveis podem representar um risco de privacidade.
  • A estrutura sugerida pela IA precisa ser analisada por alguém com conhecimento de banco de dados.

Classificação de sistemas de IA

Clique em cada sistema para visualizar sua classificação.

1. Filtro de spam

Finalidade: Identificar e-mails indesejados.

Abrangência: Estreita.

Saída: Não generativa.

Evidência: Baseia-se em padrões e dados de e-mails.

2. Gerador de imagens

Finalidade: Criar imagens a partir de comandos.

Abrangência: Estreita.

Saída: Generativa.

Evidência: Gera novos conteúdos com base no treinamento.

3. Recomendador de filmes

Finalidade: Recomendar filmes ao usuário.

Abrangência: Estreita.

Saída: Não generativa.

Evidência: Utiliza histórico, preferências e padrões de comportamento.

4. Assistente que cria testes

Finalidade: Criar questões e testes automaticamente.

Abrangência: Estreita.

Saída: Generativa.

Evidência: Produz novos textos e questões a partir de instruções.

5. Detector de fraude

Finalidade: Identificar possíveis transações fraudulentas.

Abrangência: Estreita.

Saída: Não generativa.

Evidência: Analisa padrões e identifica comportamentos suspeitos.

6. Chatbot baseado apenas em regras

Finalidade: Responder perguntas seguindo regras pré-programadas.

Abrangência: Estreita.

Saída: Não generativa.

Evidência: As respostas dependem de regras previamente definidas.

7. Sistema hipotético que aprende qualquer tarefa intelectual

Finalidade: Realizar diferentes tarefas intelectuais.

Abrangência: Geral.

Saída: Generativa.

Evidência: É uma hipótese de IA geral. Não existe evidência de um sistema assim plenamente realizado.

8. Aplicativo anunciado apenas como “superinteligente”

Finalidade: Não é possível determinar.

Abrangência: Não comprovada.

Saída: Não comprovada.

Evidência: Não há evidência suficiente, apenas uma afirmação de marketing.
