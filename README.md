# Uso de IA na Organização de Dados

Projeto desenvolvido como atividade acadêmica com o objetivo de explorar o uso da Inteligência Artificial na organização e preparação de dados para a criação de um banco de dados.

## Sobre o projeto

A proposta da atividade foi representar uma situação em que a Inteligência Artificial pode auxiliar na organização de informações inicialmente desestruturadas, identificando padrões, inconsistências e possíveis formas de estruturar os dados.

Além disso, o projeto apresenta exemplos de sistemas de Inteligência Artificial classificados de acordo com sua abrangência e tipo de saída, diferenciando sistemas de IA estreita, IA geral, generativos e não generativos.

## O que foi abordado

* Organização e preparação de dados de planilhas
* Identificação de dados duplicados e inconsistentes
* Estruturação de informações para um banco de dados
* Benefícios do uso de IA na preparação de dados
* Importância da supervisão humana
* Limitações e riscos relacionados ao uso de IA
* Classificação de sistemas de IA quanto à abrangência
* Diferença entre sistemas generativos e não generativos

A atividade teve como objetivo desenvolver uma compreensão prática sobre aplicações da Inteligência Artificial, especialmente no contexto de organização de dados, além de analisar diferentes sistemas de IA e suas características.
